# Управление режимом калькулятора

Статус калькулятора меняется в действующей админке Tekstura: `/admin/` → «Калькулятор» → «Режим калькулятора». После сохранения значение записывается в поле `calculator_mode` строки `public.settings` с `id = 1` в Supabase.

Доступны три режима:

- **Рабочий (`production`)** — клиент видит обычный калькулятор.
- **На доработке (`maintenance`)** — клиент видит заглушку и кнопку «Оставить заявку».
- **Preview / тестовый (`preview`)** — калькулятор видят только пользователи, у которых в текущей вкладке браузера установлен `sessionStorage`-ключ `tekstura_calculator_preview_access` со значением `enabled`. Остальные клиенты видят production-режим.

Если Supabase недоступен, запрос завершился ошибкой или по таймауту, поле отсутствует либо содержит неизвестное значение, калькулятор автоматически использует безопасный режим `production`.

Подробная инструкция: [`docs/calculator-mode-admin-guide.md`](docs/calculator-mode-admin-guide.md).
