# Рабочий пошаговый калькулятор

Из корня сайта запустите `python -m http.server 4173 --bind 127.0.0.1`. Откройте `http://127.0.0.1:4173/calculator.html?interface=stepwise`. Адрес без параметра открывает прежний интерфейс для сравнения. При локальной проверке используйте тестовые справочники или встроенные значения калькулятора.

Карточки основания, форма лестницы, размеры, детали основания, материалы и ограждение используют поля существующего калькулятора. Для пустого проёма шаг деталей готового основания пропускается. На шаге результата сначала показываются геометрия и предупреждения, затем доступны предварительная цена или переход к инженерной проверке. Ссылка на заявку передаёт расчёт в текущей вкладке через короткий идентификатор. При перезагрузке той же вкладки расчёт доступен в течение 30 минут.

## Общие тарифы через админку

Миграция `20261114192425_stepwise_pricing_settings.sql` создаёт отдельную запись для прочих расходов и городов. Начальные значения: 15,924%, Татарстан 2,7, Москва 3,0. На тестовом экземпляре примените миграцию и выдайте согласованной учётной записи право `app_metadata.calculator_pricing_admin = true` через серверное администрирование Auth. После повторного входа откройте «Настройки → Города и прочие расходы», сохраните изменение и откройте калькулятор в другом браузере. При конфликте двух редакторов более ранняя версия формы не перезаписывает новую.

В тесте SQL выполнялся в изолированном PostgreSQL через PGlite. Проверены публичное чтение, отказ в записи посетителю и обычному пользователю, проверка границ коэффициента и запись редактором. Через локальный тестовый HTTP-адаптер Chromium проверил добавление города в редакторе и применение его коэффициента в отдельном браузерном сеансе. Для выпуска остаются проверка реального Supabase Auth и PostgREST на согласованном тестовом экземпляре и выбор учётной записи редактора. Доступ к странице пошагового калькулятора по-прежнему ограничен локальным адресом.

На ширине 390 px проверены пустой проём, металлокаркас и бетонное основание. Для каждого варианта браузер сравнил полный расчёт и данные заявки с прежним интерфейсом на ширине 1280 px. Обе версии использовали одинаковые тестовые цены и копию файла геометрии Homelab с SHA-256 `e67988f35c173c026e5592de4298141c83ec7a36f1927162a27e8ab2ca45f363`. Этот файл проверен отдельно от ветки. Перед развёртыванием необходимо согласовать исходник геометрии для поставки и повторить сравнение на выбранной сборке и согласованных конфигурациях лестниц.
